# Codebook: `dag_answers.csv`

`dag_answers.csv` holds every answer that dagitty, the R package for causal graphs (Textor et al. 2016, *International Journal of Epidemiology*), gives to the questions of Task 2 of the [browser lab](../lab.qmd) for the four graphs to which the graph cell of the lab leads: the graph as the cell draws it, with seven arrows, and the same graph with the arrow of the claim (`period -> marriage`), the arrow from the period to the age at the start (`period -> age_start`), or both switched on. The downloadable workspace asks dagitty itself. The browser lab cannot, because dagitty runs its graph algorithms in a JavaScript engine that a browser grants only to a page served with cross-origin isolation headers, and the course site does not send them. The lab therefore reads this table: `make_dag()` turns the arrows of the cell into the key in the column `arrows`, and `adjustmentSets()`, `isAdjustmentSet()` and `paths()` print the stored answers in the form in which dagitty prints them. A graph or a question that the table does not hold gets a message that points to the workspace. The file is written by `R/cohabitation/07_dag_answers.R` with dagitty 0.3.4.

Each graph has one row for each minimal adjustment set for the total and for the direct effect of the period on marriage; one row for each path between the period and marriage under each of eight conditioning sets: none; the selection into cohabitation (`cohabits`), which every comparison of the data holds fixed, alone, with the age at the start (`"age"` on the menu), with education and race-ethnicity, and with all three (`"composition"`); and, without the selection, the age at the start alone, education and race-ethnicity, and all three; and one row for whether each of those sets is an adjustment set for the total effect. The graphs have three, six, four and seven paths, so the file has 200 rows.

| Column | Meaning |
|:--|:--|
| `graph` | The number of the graph: 1 as the cell draws it, 2 with `period -> age_start`, 3 with `period -> marriage`, 4 with both |
| `added` | The arrows switched on beyond the seven that the cell draws, separated by `; `; empty for graph 1 |
| `arrows` | Every arrow of the graph, written `cause -> effect`, sorted in the C locale and separated by `; `, the key by which the lab finds the graph |
| `exposure`, `outcome`, `latent` | The roles declared in the call to `make_dag()`: the period, marriage, and no variable that nobody observed (empty) |
| `call` | The question that the row answers: `adjustmentSets`, `paths` or `isAdjustmentSet` |
| `effect` | For an adjustment set or the check of one, the effect for which it is valid, `total` or `direct`; `NA` for a path |
| `Z` | For a path or the check of a set, the variables on which the comparison conditions, sorted and separated by commas, and empty when it conditions on nothing; `NA` for an adjustment set |
| `item` | The position of the set or the path in the output of dagitty, 1 for the check of a set. A graph for which no adjustment set exists would have one row with 0, which no graph of the task has |
| `answer` | For an adjustment set, its variables separated by commas, empty for the empty set, which dagitty prints as `{}`; for a path, the path as dagitty writes it, for example `period -> cohabits <- race -> marriage`; for the check of a set, `TRUE` or `FALSE` |
| `open` | For a path, `TRUE` when it is open given the variables in `Z` and `FALSE` when they block it; `NA` otherwise |

In every graph the minimal adjustment set for the total effect is the empty set, because nothing in the graph causes the period in which a union began. Conditioning on the selection into cohabitation opens the paths that run through it, a common effect of the period, of education and of race-ethnicity; holding education and race-ethnicity constant as well closes them again, and dagitty then counts the selection with education and race-ethnicity as an adjustment set, because the selection lies on no causal path from the period to marriage. Once the period shapes the age at the start (graphs 2 and 4), the age at the start is a mediator: any set that holds it constant is no longer an adjustment set for the total effect, and the age at the start and education form the minimal set for the direct effect.
