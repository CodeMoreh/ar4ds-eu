Replication Information for: 

“Does Race Affect Access to Government Services?: An Experiment Exploring Street Level Bureaucrats and Access to Public Housing”

Katherine Levine Einstein and David M. Glick 

American Journal of Political Science

The public replication content includes five files.  The main files are modified versions of those used to produce the paper. Privacy concerns restrict us from publicly posting the full data. The data we collected and used in the paper included FIPS codes to identify observations and to match housing authorities to the demographics of their communities via the census. Including these FIPS codes would reveal the identities of the housing authorities / officials in the data.  Whether or not a housing official responded, particularly to an ostensible minority applicant, is very sensitive and potentially harmful information. Moreover, the community demographics we include in our statistical models (e.g. city population, HUD assessment scores) also uniquely identify the observations (it would take little effort to match these data to the census) and present the same problem as naming the cities or including the FIPS codes. 

Instead we include a slightly modified dataset and code that will enable public replication of some results in full (the experimental results that do not require demographic variables), and approximations of others (the results that do require demographics). We have created blinded versions of the potentially identifying data by converting continuous variables (total population, percent black, percent white, percent Hispanic, and poverty rate, HUD assessment scores) into indicator variables capturing whether the community was in the top, middle, or bottom third of the sample population for each. These variables protect anonymity and the basic substantive results we focus on replicate when using them.  We also included the original DO file and codebook that correspond to the identifiable data used in the paper. 

The five files: 

1) A data file (STATA format): HousingAuditAJPSFinalPublic_Unidentified.dta

2) An annotated STATA .do file to reproduce the aforementioned mix of exact and approximate replications: AJPSReplicationBlind.do

3) A codebook (the STATA file also includes the codebook information) that includes the variables for the blinded data: HousingAuditCodebookBlindedData.pdf  

4) An annotated STATA .do file that reproduces all of the results in the paper using the identifiable (un-posted) data. (Allows others to see all of the steps): 
AJPSReplicationIdentifiable.do

5) A codebook (the STATA file also includes the codebook information) that includes the variables for the identifiable data: HousingAuditCodebookIdentifiedData.pdf
